# Seryj's Minecraft Launcher

Навайбкоженый, опенсорсный и простой пиратский лаунчер для Minecraft, позволяющий запускать официальный клиент, а также модификации Vanilla, Fabric и Forge.

## Особенности и возможности
* Доступность — лаунчер является пиратским, но без проблем запускает официальный Minecraft.
* Поддержка модов — полная совместимость с Vanilla, Fabric и Forge.
* Сборка в .exe — добавлена возможность компиляции в исполняемый файл (функционал полностью совпадает с оригинальным скриптом).

## Системные требования и важные ограничения
* ОС: Работает только на Windows 10 и Windows 11.
* Автогенерация: После первого запуска лаунчер автоматически создаст в своей рабочей директории папку .minecraft и конфигурационный файл launcher_settings.json.
* Важно про модификации: При скачивании модифицированной версии Minecraft (Forge/Fabric) лаунчер загружает и обычный клиент, и саму модификацию. Они оба появятся в списке версий. Обычный клиент ни в коем случае нельзя удалять! Если его удалить, модификация перестанет работать и вернуть её к жизни будет невозможно.

## Стек технологий
* Язык: Python 3.11.9+
* Интерфейс: tkinter с современной темой оформления sv_ttk
* Консоль: colorama для красивого вывода в терминал

## Установка и запуск из исходников
Если вы хотите запускать лаунчер как Python-скрипт, установите все необходимые библиотеки одной командой:

```bash
pip install Pillow minecraft_launcher_lib requests sv_ttk colorama
```

После установки зависимостей запустите главный файл проекта.
