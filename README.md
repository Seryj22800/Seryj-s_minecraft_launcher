# Seryj's minecraft launcher.
Это навайбкоженый лаунчер для Minecraft: Vanilla, Fabric, Forge.
Python: 3.11.9+ с tkinter.
Команда для установки библиотек: pip install Pillow minecraft_launcher_lib requests sv_ttk.
После запуска лаунчер создаст в катологе, в котором он находится .minecraft и launcher_settings.json.
Лаунчер пиратский, но запускает оффицальный Minecraft.
Использование лаунчера как собранного приложения не предусмотренно.
